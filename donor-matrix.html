③ 政策曝險矩陣（取代黨派標籤）

七個維度評分 −3…+3。正數 = 受益於民主黨政策方向（補貼擴張、加強監管、減息、財富重分配）；負數 = 受益於共和黨方向（去監管、化石擴張、加密寬鬆、國防擴張）。
維度傳導機制
subsidy依賴聯邦補貼／稅務優惠（IRA、CHIPS、農業法案）
govContract依賴聯邦合約（國防、拘留、醫療給付）
regulation正數 = 受益於更多監管（合規護城河）；負數 = 被監管打擊
rates存續期敏感度。正數 = 長存續期，受益減息；負數 = 受益加息（銀行利差）
wealthTax財富稅／資本利得稅／按市值課稅曝險。負數 = 直接受損
crypto加密監管友善度。正數 = 受益於寬鬆
tariff關稅曝險。正數 = 受益於進口關稅（本土生產商）；負數 = 依賴進口
